# Cutroom 설치 파일

컷룸 0.3.0 테스트 설치 파일을 Windows, Apple Silicon Mac, Intel Mac용으로 제공합니다.

사이트에서 사용 중인 버전을 확인하고 업데이트가 있으면 새 설치 파일을 안내합니다. 작업을 저장하고 Premiere를 종료한 뒤 새 설치 파일을 실행하세요. 기존 Cutroom을 교체하며 프로젝트와 API 설정은 유지합니다.

Mac에서는 DMG 안의 Cutroom을 실행하면 응용 프로그램 폴더의 기존 앱을 교체합니다. Apple 서명·공증 전 테스트 버전이므로 macOS에서 실행이 차단될 수 있습니다. Windows 설치 파일도 정식 서명 전 테스트 버전입니다.
